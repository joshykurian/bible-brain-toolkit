# About and useful links

## About this toolkit
The Bible Brain Toolkit is a free, open-source set of tools for putting Bible Brain audio, video and text on websites: a WordPress plugin,
a Drupal module, a Joomla plugin, an HTML5 embed with a small proxy, and a desktop downloader. Scripture content is provided by
[Bible Brain](https://www.faithcomesbyhearing.com/audio-bible-resources/bible-brain), a project of [Faith Comes By Hearing](https://www.faithcomesbyhearing.com/). See [NOTICE.md](../NOTICE.md).

### What you get
| Tool | What it does |
|---|---|
| **WordPress plugin** | Shortcodes for a Bible reader, an audio player and a video player, a settings page, and a built-in proxy that keeps your key private. |
| **Drupal module** | A "Bible Brain player" block with a settings form and a built-in proxy route. |
| **Joomla plugin** | Short tags that place a player anywhere in an article, with a built-in proxy. |
| **HTML5 embed** | A few lines of HTML for any website, plus a small standalone PHP proxy and a code generator. |
| **Downloader** | A desktop app and command line tool that saves Bible text and audio as ZIP files. |

All of them share one player, so visitors get the same experience everywhere:
- audio and video first, with the text reader as a companion that can play the audio and highlight verses;
- a country, language and version selector, with right-to-left support and draft interface translations for Hindi, Bengali, Nepali, Sinhala, Urdu and Malayalam;
- links that reopen the same chapter, one-tap sharing to WhatsApp, Telegram and Facebook, and optional analytics events;
- your API key stays on your server, with caching and a rate limit.

Try the players in your browser on the [demo website](https://www.shalomdesigns2dio.com/bible-brain-toolkit/).
