# Roadmap

These are **ideas**, not promises. Open an issue to vote for, change or add something.

## Near term
- Native-speaker review of the six bundled translations, and more languages (Tamil, Telugu, Kannada, Marathi, Punjabi, Gujarati, Dzongkha)
- Real-CMS test runs for WordPress, Drupal and Joomla, and publication in their official directories
- A Gutenberg block for WordPress and a Drupal Layout Builder preview
- A WordPress settings preview and a "test my key" button
- Optional per-element language so several languages can live on one page

## Reach and sharing
- **Progressive web app** shell: installable, with an offline shell and remembered position
- **QR code** and printable "listen here" cards generated from any player link
- **Short links and SMS-friendly links** for low-data environments
- **WhatsApp and Telegram bot** that replies with a chapter link and audio in the user's language
- **Podcast / RSS feeds** from any audio fileset so people can use their usual podcast app
- **Radio and IVR helpers** (playlists for community radio, phone-call menus) where internet use is low

## Engagement and discipleship
- Optional **listening-group guides**: printable discussion cards built from a passage
- **Reading and listening plans** (for example 30 days in a Gospel) with a daily share link
- **Story sets** for oral Bible storytelling, using the video player's clip lists
- A **response form** option that sends a reflection to a ministry email, built with strong privacy defaults
- **Email or message reminders** via a simple opt-in

## Technical
- Chapter-level **audio download** button for offline use where the licence allows it
- A **React/Vue component** and an `npm` package for app developers
- A tiny **Node/Python proxy** for hosts without PHP, and a **Cloudflare Workers** proxy
- A **mobile app wrapper** (Capacitor or similar) using the same player
- More automated tests for the CMS wrappers (WordPress test suite, Drupal kernel tests, Joomla integration tests)
- Accessibility audit with screen-reader users
