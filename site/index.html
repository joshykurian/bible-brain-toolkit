    See your own content

    Already running the plugin or the HTML5 proxy? Paste its address and these players will show real Bible Brain content from your server. Your key is never entered here.

    The address must use https, and your proxy must allow this website (allowed_origins). Examples: https://yoursite.org/wp-json/bbp/v1/, https://yoursite.org/bible-brain/api/, https://yoursite.org/index.php?bbapi=.

    About

    The Bible Brain Toolkit is a free, open-source set of tools for putting Bible Brain audio, video and text on websites: a WordPress plugin, a Drupal module, a Joomla plugin, an HTML5 embed with a small proxy, and a desktop downloader.

    Developed by Shalom Design S2dio (SDS), with the help of AI tools. This is an unofficial community project and is not published or supported by Faith Comes By Hearing. This is an AI-assisted ("vibe coded") project: the developer set the goals and checked the results, and Claude (Anthropic), used through Claude Code, wrote most of the code. Please test it on a staging site before you rely on it.

    Scripture content is provided by Bible Brain, a project of Faith Comes By Hearing. Please follow the license and copyright terms of every Bible version you publish.

    Questions about your key or content licenses: support@digitalbibleplatform.com
